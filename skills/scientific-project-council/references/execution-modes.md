# Execution compatibility

Select execution mode from the tools actually exposed in the current conversation, not the product name or installed skill format. A skill cannot create an unavailable delegation tool.

## AUTO (default)

If fresh isolated reviewer contexts are available, use INDEPENDENT COUNCIL and the five sequential dispatches. If delegation is absent or denied, continue immediately in SINGLE-CONTEXT REVIEW. Do not stop at normalization, create an empty council, or ask the student to move platforms. Disclose once: "Single-context review: five sequential perspectives from one conversation; reviewers are not independent."

In SINGLE-CONTEXT REVIEW, perform Believer, Skeptic, Domain Expert, Research Architect, and Academic Judge in order as explicitly labeled analytical stages in the current conversation. Apply the complete assigned role prompt and operating addendum at each stage, then quality-check that stage before continuing. The coordinator executes these stages directly; do not fabricate agent calls, IDs, fresh contexts, or separate model executions. Earlier stages remain visible and anchoring cannot be eliminated. The authorized-payload table describes intended evidence use, not enforced context isolation in this mode.

For this mode only, interpret "independent reviewer" as "assigned analytical perspective" and "four independent reviews" as "four preceding analytical stages." The role prompts' substantive questions, verdict gates, evidence standards, and objection handling remain unchanged. Coordinator research tools may be used during the Domain Expert stage. If browsing is available, conduct the prior-art search; lack of delegation alone does not prohibit research. If browsing is unavailable, disclose search limits as usual.

Finish all five stages, quality control, a Judge verdict, action plan, and persistence. Put EXECUTION: SINGLE-CONTEXT REVIEW in both the user-facing report and saved transcript. Label the verdict an advisory single-context judgment, never an independent council ruling. COMPLETE means all required stages and checks finished in the recorded execution mode; it does not certify reviewer independence. Never invent empirical project results.

One corrective revision per stage and ten total stage attempts remain the full-review limit. Record stage names and attempts, with agent ID NOT APPLICABLE. A genuine unfinished stage still produces INCOMPLETE/PENDING. Do not downgrade an independent run silently after a reviewer fails: disclose any mode change and redo all five stages in single-context mode as a new evaluation, rather than mix outputs and imply full isolation.

## STRICT INDEPENDENT (explicit request)

When the student requests strict independent agents, fresh sessions, or prohibits same-context review, do not fall back. If delegation is unavailable, explain the limitation, save INCOMPLETE/PENDING, and actually provide the complete first dispatch prompt with instructions for the remaining sequential handoffs. Never refer to an uncreated dispatch packet as though it exists. A manual fresh-session workflow is permitted, but external messaging requires user authorization.

## Follow-ups and history

Keep each saved record's execution mode visible. A Judge-only evidence update inherits the limitations of its earlier reviews even if the new Judge has an isolated context. Never upgrade a SINGLE-CONTEXT REVIEW record to an independent council by changing its label; a new independent full council must rerun all roles. For AUTO follow-ups without delegation, perform the applicable Judge stage in the current context and retain the advisory label. Existing INCOMPLETE/PENDING records have no previous verdict; start a full evaluation and link the incomplete attempt.
